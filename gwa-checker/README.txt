GWA Checker for University of the East

This folder is part of the site. It uses the shared ../styles.css and ../theme.js,
so keep it inside the site folder (next to the root index.html).
Open the root index.html (or this folder's index.html) in a browser. No server needed.
The Google Fonts link needs internet; the page falls back to system fonts offline.

Non-numeric grades (LFR, W, D, IP, LOA, GRWH, blank, anything else) are not counted.
The page lists them. 'D' (unofficially dropped) can optionally be counted as 5.00 via a tick box (off by default).
